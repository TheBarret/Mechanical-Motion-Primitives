# Mechanical-Motion-Primitives
Mechanical implementation to mathematical mappings

Classifications:
```
# CLASS I: LINEAR SCALING (Affine Maps) (finished and tested)
Continuous, invertible, constant ratio

# CLASS II: PERIODIC NON-LINEAR (Trigonometric) (finished and tested)
Oscillatory, bounded, non-injective without domain restriction

# CLASS III: CONFIGURATION-DEPENDENT (Mode-Switchable) (to do)
Same hardware, different equations based on constraint

# CLASS IV: QUANTIZING / DISCRETIZING (to do)
Continuous input → stepped output

# CLASS V: ONE-WAY / IRREVERSIBLE (to do)
Physically non-backdrivable

# CLASS VI: HIGH-RATIO / OBFUSCATING (to do)
Extreme scaling that obscures relationship

# CLASS VII: COMPLEX PATH / MULTI-DIMENSIONAL (to do)
Produces curves in 2D or higher spaces

# CLASS VIII: COINCIDENCE / RESONANT (to do)
Output only at specific alignments
```
